# Plan: Fix Infinite Loop in DataPipelineWorkspace & Remove SUC-* from UI

## 1. Context & Root Cause Analysis

### Bug 1: Infinite loop in `DataPipelineWorkspace.tsx`
- **Symptom:** React error `Maximum update depth exceeded` triggered at `DataPipelineWorkspace.tsx:242` through `onConfigChange` in `SchemaMappingWorkspace.tsx:100`. The browser tab / React tree freezes or breaks routing.
- **Root Cause:**
  - In `DataPipelineWorkspace.tsx`, `onConfigChange` was passed as an inline anonymous function:
    ```tsx
    onConfigChange={(cfg, valid) => {
      setMappingConfig(cfg);
      setIsMappingValid(valid);
    }}
    ```
    This allocates a new function instance on every single render of `DataPipelineWorkspace`.
  - In `SchemaMappingWorkspace.tsx`, `useEffect` depends on `[..., onConfigChange]`.
  - When `SchemaMappingWorkspace` mounts, the effect fires and calls `onConfigChange(payload, isAllMandatorySatisfied)`.
  - `DataPipelineWorkspace` receives the callback and calls `setMappingConfig` / `setIsMappingValid`, forcing a re-render.
  - The re-render instantiates a brand new `onConfigChange` callback reference.
  - `SchemaMappingWorkspace` detects that `onConfigChange` has changed reference, so its `useEffect` fires again.
  - This forms an infinite render loop exceeding React's update depth limit.
  - In addition, `FeatureEngineeringWorkspace.tsx` has a similar pattern with `onConfigChange` in its effect dependency list.

### Bug 2: Remove all `SUC-<number>` from UI
- **Symptom:** UI headers, modal titles, and KPI descriptions show internal specification codes (`SUC-08`, `SUC-09`, `SUC-10`, `SUC-12`, `SUC-15`, `SUC-17`, `SUC-27`).
- **Files identified:**
  1. `ActivateModelModal.tsx`: Title `(SUC-10)` and description `(SUC-15)`.
  2. `ImportCustomModelModal.tsx`: Title `(SUC-17)`.
  3. `ModelHubView.tsx`: Header badge `SUC-27` and KPI subtitle `(SUC-15)`.
  4. `TrainingRunDetailView.tsx`: Loading text `(SUC-09)` and header badge `SUC-09`.
  5. `TrainingWizardView.tsx`: Header badge `SUC-08`.
  6. `RuleDryRunWorkspace.tsx`: Tab label `Historical Dataset Backtest (SUC-12)`.

1. **Fix Infinite Loop in Data Pipeline Workspace**:
   - In `DataPipelineWorkspace.tsx`: Wrap mapping config handler in `useCallback` with empty dependency array `[]`.

   - In `FeatureEngineeringWorkspace.tsx`: Apply the same `useRef` protection for `onConfigChange`.
