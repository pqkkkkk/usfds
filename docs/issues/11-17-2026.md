## ISS-038: Training evaluation metrics misaligned with TASK-105 specification
- **Status:** Planned <!-- [26-11-17] -->
- **Type:** improvement · **Area:** training, web · **Priority:** P2
- **Plan:** `.plan/training_evaluation_metrics.md`
- **Impact / Root cause / Facts:**
  - `MetricEvaluator` (`usfds-core/src/usfds_core/services/training/evaluators/metric_evaluator.py`) and `_usfds_runner.py` lack `MCC`, `Precision@k`, `Precision@0.2 Recall`, `AUC-PR Card`, and `Card Precision@k (CP@k)`, while still emitting unrequested metrics (`youden_j`, `high_recall_90`, `high_recall_95`, `score_distribution`, `log_loss`).
  - `usfds-web` (`TrainingRunDetailView.tsx`, `ModelHubView.tsx`, `types/metrics.ts`, `types/model.ts`) does not display the 3 metric groups and card-level PR curve specified in Notion `TASK-105` (`SUC-09`, `SUC-27`).
- **Direction / Fix:**
  - Implement all 11 `TASK-105` metrics in `MetricEvaluator`, wire `card_ids` and `timestamps` in `BuiltinModelTrainer`/`ScriptPluginTrainer`/`_usfds_runner.py`, deprecate unmentioned metrics, and update `usfds-web` + `docs/features/detection/training/suc-spec.md`.

## ISS-039: No AutoML (Optuna Bayesian Optimization) in model training flow
- **Status:** Planned <!-- [26-11-17] -->
- **Type:** feature · **Area:** training, server, web · **Priority:** P2
- **Plan:** `.plan/automl_training_integration.md`
- **Impact / Root cause / Facts:**
  - `usfds-core` has no `automl` optimizer (`usfds-core/src/usfds_core/services/training/automl/` does not exist); `BuiltinModelTrainer` and `ScriptPluginTrainer` train only with static hyperparameters without joint preprocessing + model hyperparameter tuning (`SUC-08`, Notion `TASK-113`).
- **Direction / Fix:**
  - Add `optuna>=3.6.0` and `BayesianPipelineOptimizer` using chronological train/val split + full-train refit for both `BUILTIN` and `SCRIPT` models, expose `automl_config` in `training_router.py`, and add AutoML configuration & optimization report UI in `TrainingWizardView.tsx` and `TrainingRunDetailView.tsx`.
